* Manual Classification

Suppose:

#+begin_quote
x_new = 3.5 hours
#+end_quote

Question:

#+begin_quote
Would you classify this as pass or fail?
#+end_quote

Answer:
#+begin_quote
A value on the decision boundary is ambiguous. It's a tie without a
unique answer unless you specify a tie-breaking rule. Our algorithm
has to break the tie.
#+end_quote

* k-Nearest Neighbors (kNN)

Algorithmic idea:

- Look at the closest data points
- Let them “vote”

Steps:

1. Choose a value for =k=
2. Find the k nearest neighbors
3. Take majority vote

* Example: k = 1

For =x_new = 3.5=:

- Closest point: x = 3 (fail)

Prediction:

#+begin_quote
fail (0)
#+end_quote

* Example: k = 3

Neighbors:

- x = 3 → 0
- x = 4 → 1
- x = 2 → 0

Vote:

- 2 fail vs 1 pass

Prediction:

#+begin_quote
fail (0)
#+end_quote

* Example: k = 5

Neighbors:

- all points

Vote:

- 3 fail vs 2 pass

Prediction:

#+begin_quote
fail (0)
#+end_quote

* Example: k = 2

- Using k = 2 makes ties more likely

- Odd k reduce the chance of ties (there's always a majority)

- Even k increase the chance of ties

- This is only true for (unweighted) binary classification

* Key Observation

Changing =k= changes the model.

- small k → sensitive to noise
- large k → smoother, more stable

* SOMEDAY Overfitting vs Smoothing

- k = 1 → fits data very closely (may overfit)
- larger k → averages behavior

#+begin_quote
The model trades sensitivity for stability.
#+end_quote

Visualizing the smoothing effect as k gets larger, on a larger
dataset, for a family of decision curves:

  import numpy as np
  import matplotlib.pyplot as plt
  from sklearn.neighbors import KNeighborsClassifier

  # Larger 1D classification dataset
  x = np.array([
      1.0, 1.5, 2.0, 2.2, 2.8, 3.0, 3.3, 3.8,
      4.2, 4.5, 5.0, 5.5, 6.0, 6.5, 7.0, 7.5
  ]).reshape(-1, 1)

  y = np.array([
      0, 0, 0, 0, 0, 0, 1, 0,

  ])

  xx = np.linspace(0.5, 8.0, 600).reshape(-1, 1)

  # Many odd k values
  k_values = range(1, 16, 2)

  plt.figure(figsize=(10, 5))

  # Plot training data
  plt.scatter(x, y, s=50, label="data")

  plt.yticks([0, 1], ["fail", "pass"])
  plt.title("kNN decision curves for increasing k")

* Using scikit-learn (kNN)

#+begin_src python :results output :exports both :session *Python* :python python3
  # Import the k-nearest neighbors classifier from scikit-learn
  # This provides an implementation of the kNN algorithm
  from sklearn.neighbors import KNeighborsClassifier

  # Create a kNN model object
  # n_neighbors=3 means: look at the 3 closest training points
  # and let them vote to determine the class (k=3)
  model = KNeighborsClassifier(n_neighbors=3)

  # Train (fit) the model using the training data
  # x: input features (hours studied), shape = (n_samples, n_features)
  # y: target labels (0 = fail, 1 = pass)
  # The model stores the data internally (kNN is a "lazy learner")
  model.fit(x, y)

  # Make a prediction for a new data point
  # [[3.5]] means:
  # - one sample (outer list)
  # - one feature (inner value: hours studied)
  # Shape = (1, 1), which is required by scikit-learn
  # The model will:
  #   1. compute distances from 3.5 to all training points
  #   2. select the 3 nearest neighbors
  #   3. take a majority vote among their labels
  #   4. return the predicted class (0 or 1)
  prediction = model.predict([[3.5]])

  # Print the prediction
  # Output is an array, e.g. [0] meaning "fail"
  print(prediction)

#+end_src

#+RESULTS:
: [0]

6. Compare predictions for different k nearest neighbors

   #+begin_quote
   Do the predictions differ? Why or why not?
   #+end_quote

   Answer:
   #+begin_quote
   The predictions do not differ. For both k=1 and k=3, the model
   predicts 1 (approved).

   Why? The value 4.5 lies between 4 and 5, and both of these nearest
   neighbors belong to class 1. When k = 3, two of the three nearest
   neighbors 4 (1), 5 (1) are class 1. There is a tie for the third,
   either 3 (0) or 6 (1) because they are equally distant.

   There is no tie-breaking rule here so whatever appears first in =income=
   is chosen - in this case 3, but that does not affect the outcome.
   #+end_quote

* Question

#+begin_quote
In one sentence: how does changing k affect the decision?
#+end_quote

Answer:
#+begin_quote
Changing k makes the model consider more nearby examples, which
usually makes the prediction more stable and less sensitive to any one
single data point.
#+end_quote

* Key Points

- Classification predicts categories instead of numbers
- A decision boundary separates classes
- kNN classifies based on similarity to known examples
- The parameter k controls model complexity
- Predictions depend on local data structure
