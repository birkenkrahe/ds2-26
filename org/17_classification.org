#+end_quote

* k-Nearest Neighbors (kNN)

Algorithmic idea:

- Look at the closest data points
- Let them “vote”

Steps:

1. Choose a value for =k=
2. Find the k nearest neighbors
3. Take majority vote

* Example: k = 1

For =x_new = 3.5=:

- Closest point: x = 3 (fail)

Prediction:

#+begin_quote
fail (0)
#+end_quote

* Example: k = 3

Neighbors:

- x = 3 → 0
- x = 4 → 1
- x = 2 → 0

Vote:

- 2 fail vs 1 pass

Prediction:

#+begin_quote
fail (0)
#+end_quote

* Example: k = 5

Neighbors:

- all points

Vote:

- 3 fail vs 2 pass

Prediction:

#+begin_quote
fail (0)
#+end_quote

* Example: k = 2

- Using k = 2 makes ties more likely

- Odd k reduce the chance of ties (there's always a majority)

- Even k increase the chance of ties

- This is only true for (unweighted) binary classification

* Key Observation

Changing =k= changes the model.

- small k → sensitive to noise
- large k → smoother, more stable

* Using scikit-learn (kNN)

#+begin_src python :results output :exports both :session *Python* :python python3
  # Import the k-nearest neighbors classifier from scikit-learn
  # This provides an implementation of the kNN algorithm
  from sklearn.neighbors import KNeighborsClassifier

  # Create a kNN model object
  # n_neighbors=3 means: look at the 3 closest training points
  # and let them vote to determine the class (k=3)
  model = KNeighborsClassifier(n_neighbors=3)

  # Train (fit) the model using the training data
  # x: input features (hours studied), shape = (n_samples, n_features)
  # y: target labels (0 = fail, 1 = pass)
  # The model stores the data internally (kNN is a "lazy learner")
  model.fit(x, y)

  # Make a prediction for a new data point
  # [[3.5]] means:
  # - one sample (outer list)
  # - one feature (inner value: hours studied)
  # Shape = (1, 1), which is required by scikit-learn
  # The model will:
  #   1. compute distances from 3.5 to all training points
  #   2. select the 3 nearest neighbors
  #   3. take a majority vote among their labels
  #   4. return the predicted class (0 or 1)
  prediction = model.predict([[3.5]])

  # Print the prediction
  # Output is an array, e.g. [0] meaning "fail"
  print(prediction)

* Visualize over and underfitting

- Over- and underfitting as a function of =k= is easier visualized in a
  two-dimensional example:
  + for =k=1= (overfit) the boundary is jagged and closely wraps
    individual points.
  + moderate =k= (good fit) separates the point clusters cleanly.

- Code example:
  #+begin_src python :results none :exports both :session *Python* :python python3 
    import numpy as np
    import matplotlib.pyplot as plt
    from sklearn.neighbors import NearestNeighbors

    # dataset
    X = np.array([
        [1,1],[2,1],[1,2],
        [4,4],[5,4],[4,5]
    ])
    y = np.array([0,0,0,1,1,1])

    # query point
    x_new = np.array([[3,3]])

    def show_neighbors(k):
        nn = NearestNeighbors(n_neighbors=k)
        nn.fit(X)

        distances, indices = nn.kneighbors(x_new)

        plt.scatter(X[:,0], X[:,1], c=y, s=80)
        plt.scatter(x_new[:,0], x_new[:,1], c='red', s=120, marker='x')

        # highlight neighbors
        neighbors = X[indices[0]]
        plt.scatter(neighbors[:,0], neighbors[:,1],
                    facecolors='none', edgecolors='black', s=200)

        # draw circle to furthest neighbor
        r = distances[0][-1]
        circle = plt.Circle((x_new[0,0], x_new[0,1]), r,
                            fill=False, linestyle='--')
        plt.gca().add_patch(circle)

        plt.title(f"k = {k}")
        plt.xlim(0,6); plt.ylim(0,6)
        plt.gca().set_aspect('equal')
        plt.savefig(f"neighbors_k_{k}.png")
        plt.close()

    for k in [1,3,5]:
        show_neighbors(k)
  #+end_src

* Question

In one sentence: how does changing k affect the decision?

Answer:
#+begin_quote
Changing k makes the model consider more nearby examples, which
usually makes the prediction more stable and less sensitive to any one

* Key Points

- Classification predicts categories instead of numbers
- A decision boundary separates classes
- kNN classifies based on similarity to known examples
- The parameter k controls model complexity
- Predictions depend on local data structure

* SOMEDAY Overfitting vs Smoothing

- k = 1 → fits data very closely (may overfit)
- larger k → averages behavior

#+begin_quote
The model trades sensitivity for stability.
#+end_quote

  plt.plot(k_values, preds, marker='o')
  plt.xlabel("k")
  plt.ylabel("Prediction at x_new = 3.5")
  plt.yticks([0, 1], ["fail", "pass"])
  plt.title("Prediction stability as k increases")
  plt.grid(True, alpha=0.3)
  plt.savefig("kPlot2.png")

- Remove all user-defined variables

  In Colab, you can use the magic command =%reset -f= and then check
  with =%whos= what's still standing.

  In Python, you can delete from ~globals()~ (here wrapped in a
  function =clear()=):

  #+name: clear_user_defined_objects_except_imports
  #+begin_src python :results none :session *Python* :python python3
    def clear():
        for name in list(globals()):
            if name not in ['np','plt'] and not name.startswith('_'):
                del globals()[name]
  #+end_src
