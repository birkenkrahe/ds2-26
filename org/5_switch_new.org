* Overview

In this lecture you will learn:

- What stacked if statements are
- What nested if statements are
- When to use switch()
- How these structures differ
- How to choose the simplest structure

We build on:
- if
- if ... else
- else if
- ifelse()

* 1. Stacked if Statements

Stacked if statements are independent.

Each condition is checked separately.

Example:

#+begin_src R :results output :exports both :session *R*
x <- 5

if (x > 0) {
  print("positive")
}

if (x %% 2 == 1) {
  print("odd")
}
#+end_src

Both conditions may run.

Stacked if statements do NOT exclude each other.

* 2. else if Chains (Mutually Exclusive)

#+begin_src R :results output :exports both :session *R*
x <- 5

if (x > 0) {
  print("positive")
} else if (x == 0) {
  print("zero")
} else {
  print("negative")
}
#+end_src

Only one branch runs.

Order matters.

* 3. Nested if Statements

Nested means: an if inside another if.

#+begin_src R :results output :exports both :session *R*
x <- 8

if (x > 0) {
  if (x %% 2 == 0) {
    print("positive and even")
  } else {
    print("positive and odd")
  }
}
#+end_src

The inner test only runs if the outer condition is TRUE.

* 4. When to Nest vs. When to Stack

Stacked:

#+begin_src R :results output :exports both :session *R*
if (x > 0) print("positive")
if (x %% 2 == 0) print("even")
#+end_src

Nested:

#+begin_src R :results output :exports both :session *R*
if (x > 0) {
  if (x %% 2 == 0) print("positive and even")
}
#+end_src

The meaning differs.

* 5. Introducing switch()

switch() compares one value against fixed cases.

Numeric selector:

#+begin_src R :results output :exports both :session *R*
day <- 2

switch(day,
       "Monday",
       "Tuesday",
       "Wednesday",
       "Thursday",
       "Friday")
#+end_src

Character selector:

#+begin_src R :results output :exports both :session *R*
op <- "add"

switch(op,
       add = 2 + 3,
       subtract = 5 - 2,
       multiply = 3 * 4,
       "Unknown operation")
#+end_src

If no match is found, the last value is returned.

* 6. switch vs else if

Better suited for switch:

#+begin_src R :results output :exports both :session *R*
grade <- "B"

switch(grade,
       A = "Excellent",
       B = "Good",
       C = "Average",
       D = "Below Average",
       F = "Fail",
       "Invalid grade")
#+end_src

Use else if for ranges or logical comparisons.

* Summary

Stacked if:
- Independent tests

Nested if:
- Dependent structure

else if:
- Mutually exclusive chain

switch():
- Best for matching one value against fixed cases
