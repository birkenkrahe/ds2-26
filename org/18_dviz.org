* Lab goal

In this lab, we will practice choosing the right plot for a data
question.

We will use Python, but the main goal is not Python syntax. The main
goal is to understand which plot matches which kind of data.

The DataCamp lectures introduced these ideas:

- Summary statistics are useful, but they can hide patterns
- Plots help us see patterns
- Continuous variables are usually numeric
- Categorical variables are usually labels
- Different plot types answer different questions

* First plot: scatter plot

Use a scatter plot when you have two continuous variables and want to
study their relationship.

But since there are several numerical features, you first must
identify an interesting question:

Question:
#+begin_quote

#+end_quote

Make a scatter plot.

* Instructor pacing notes

This lab is intended as a code-along.

Recommended pacing:

- Setup and inspection: 10–15 minutes
- Scatter plots: 20 minutes
- Histograms: 20–25 minutes
- Box plots: 20 minutes
- Bar plots: 15 minutes
- Line plots: 15 minutes
- Final choose-the-plot section: 10–15 minutes

The important teaching move is to slow down before each plot:

1. Ask what question is being answered.
2. Identify variable types.
3. Choose the plot.
4. Run the code.
5. Interpret the visual result.

Do not add advanced Python syntax unless students are moving very fast.
